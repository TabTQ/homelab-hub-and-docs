# Design history

These are the working documents the project was built from: feature plans written as hand-off briefs, and the reports written
afterwards. They explain **why** things are the way they are (decisions, alternatives, defects found) and are kept for that reason.
Some of them speak to an "implementing agent" and mention "the owner", because that is how they were written. The code and
the top-level `README.md` and `docs/plan.md` are the current truth; where a plan and the code disagree, the code wins.

| Document | About |
|---|---|
| `budget-feature-plan.md`, `budget-implementation-report.md` | The shared-expenses Budget page |
| `terminal-feature-plan.md`, `terminal-feature-report.md` | The browser Terminal page (SSH relay) |
| `docker-feature-plan.md`, `docker-and-budget-fixes-plan.md` | The Docker page and a follow-up round of fixes |
| `docs-feature-plan.md` | The Docs app on its own LXC |
| `portfolio-on-docs-lxc-plan.md` | Moving the portfolio editing and public site to the Docs LXC |
